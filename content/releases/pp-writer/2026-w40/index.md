date: 2026-10-02
summary: "这一周更新最多：私密笔记可以加密锁定；Mac 版有了待办、收藏、最近、搜索、设置中心和沉浸模式；手机端也能搜索了。"
draft: false
items:
  - id: note-lock
    category: 新功能
    summary: "单篇笔记加密锁定"
    detail: |
      私密笔记可以单独设置密码锁定，内容加密后再保存和同步，只有输入密码才能打开。
  - id: todo
    category: 新功能
    summary: "待办"
    detail: |
      `- [ ]` 显示为可以点击的圆形复选框；左栏「待办」汇总所有待办，信息面板显示完成进度。
  - id: favorites
    category: 新功能
    summary: "收藏"
    detail: |
      笔记可以加入收藏，左栏点「收藏」查看，最新收藏的在最前，也可以拖拽调整顺序。
  - id: recent
    category: 新功能
    summary: "最近打开"
    detail: |
      左栏「最近」列出最近打开过的笔记。
  - id: search
    category: 新功能
    summary: "搜索与查找替换"
    detail: |
      中栏可以在当前文件夹里搜索；按 ⌘K 按标题和正文快速打开笔记；按 ⌘F 在笔记内查找和替换。
  - id: app-search
    category: 新功能
    summary: "手机端搜索"
    detail: |
      首页「⋯」菜单进入搜索，结果显示关键词附近的正文片段并高亮。
  - id: settings
    category: 新功能
    summary: "设置中心"
    detail: |
      账号、偏好（浅色 / 深色 / 跟随系统）、编辑器、工作区和快捷键都集中在设置中心里。
  - id: zen
    category: 新功能
    summary: "收起侧栏与沉浸模式"
    detail: |
      左栏可以收起，专注写作；沉浸模式下左上角保留展开侧栏、笔记列表和大纲的入口。栏宽也可以拖拽调整。
  - id: zoom
    category: 新功能
    summary: "缩放"
    detail: |
      类似 Typora，支持双指缩放、实际大小、放大和缩小，都有快捷键。
  - id: auto-reload
    category: 改进
    summary: "文件在别处被修改，自动刷新"
    detail: |
      笔记文件在其他程序里被修改后，小纸条会自动重新加载，不会再显示旧内容。
  - id: large-note
    category: 改进
    summary: "手机端大笔记不卡了"
    detail: |
      编辑几百 KB 的大笔记时，点按定位光标和上下滚动都恢复流畅。
  - id: stability
    category: 修复
    summary: "若干问题修复"
    detail: |
      - 修复长笔记里点击或选中落到错误行的问题
      - 修复登录一段时间后无法新建 Git 工作区的问题
      - 删除前一定会弹出确认
      - 在大纲模式下点左栏文件夹，会自动切回笔记列表
